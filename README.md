# Startup Sphere Website

Modern landing page for Startup Sphere with smooth motion, premium cursor effects, and a streaming-ready video section.

## Features
- Responsive multi-section landing layout
- Smooth scroll animations with GSAP + Locomotive Scroll
- Premium glow cursor and hover highlights
- Video embed with autoplay, loop, and streaming support
- Node static server with HTTP range for MP4

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- GSAP, Locomotive Scroll
- Node.js static server

## Project Structure
- index.html
- styles.css
- server.js
- images/
- video.mp4

## Run Locally
```bash
node server.js
```
Open http://localhost:3000

## Notes
- All images in the images/ folder are used in the featured work grid and poster.
